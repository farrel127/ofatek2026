# OFATEK 2026 — Frontend

Frontend awal website Open Recruitment Panitia OFATEK 2026.

## Stack
- HTML
- CSS
- JavaScript Vanilla
- PWA Level 1

## Status
Frontend masih menggunakan `DEMO_MODE: true`.
Belum terhubung ke Google Sheets / Google Apps Script.

## Cara menjalankan
Bisa langsung dibuka dengan static server. Contoh:

```bash
python -m http.server 5500
```

Lalu buka:
http://localhost:5500

## Konfigurasi
Edit `js/config.js`:
- `DEMO_MODE`
- `GOOGLE_APPS_SCRIPT_URL`
- `WHATSAPP_GROUP_URL`
- `REGISTRATION_DEADLINE`

## Logo
Logo OFATEK yang diberikan digunakan sebagai logo awal pada `assets/logo-ofatek.png`.
